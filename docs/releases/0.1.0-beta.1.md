# Battery for FlexBar 0.1.0-beta.1

First beta of Battery for FlexBar. Add one **Battery level** Unit for each
peripheral, select it in **Function**, and customize its font, color and
optional icon in **Foreground**. Readings refresh about once a minute or
when you tap the Unit. A lightning icon indicates charging; a crossed-out plug
indicates that a reading is unavailable.

## Hardware-tested

| Device | Tested connection |
| --- | --- |
| Logitech MX Master 4 | Logi Bolt; direct HID++, no Options+ required for the reading |
| Logitech G305 LIGHTSPEED | Original LIGHTSPEED receiver; direct HID++ tested with G HUB closed |
| Keychron M6 | 1K Keychron Link receiver |
| Lamzu Paro | 2.4 GHz receiver and USB; on-panel disconnect and recovery checked with the receiver |
| Sony DualSense | USB and Bluetooth with extended reports; the displayed percentage is an estimate |

**Additional profiles are Beta.** These include G502 LIGHTSPEED, Keychron M7,
Lamzu Aurora, selected mice and keyboards, DualSense Edge, DualShock 4,
Switch Pro, Xbox and optional HeadsetControl. Check the
[compatibility table](https://github.com/mor4ee/BatteryFlexBar/blob/public/docs/COMPATIBILITY.md)
for actual model and connection limits. A Beta profile is not a hardware-tested
compatibility claim.

## Install and verify

Install `Battery.win32.x64.flexplugin` through FlexDesigner. It targets
Windows 10/11 x64 and FlexDesigner Plugin API v1. The verified host baseline
is **FlexDesigner 2.2.3**; full hardware regression on **2.2.5 Pre-release**
is still pending. The plugin does not use FlexStudio SDK v2.

Compare the archive hash against the accompanying `SHA256SUMS.txt`:

```powershell
Get-FileHash -Algorithm SHA256 .\Battery.win32.x64.flexplugin
```
