# Battery for FlexBar 0.1.0

The first stable release of Battery for FlexBar. It promotes the Battery level
Unit from `v0.1.0-beta.1` without changing battery polling or panel rendering.
Add one Unit per peripheral, choose the device in **Function**, and customize
its font, color and optional icon in **Foreground**. Tap to refresh. A lightning
icon indicates charging and a crossed-out plug indicates an unavailable reading.

## Hardware-tested

| Device | Tested connection |
| --- | --- |
| Logitech MX Master 4 | Logi Bolt; direct HID++, no Options+ required for the reading |
| Logitech G305 LIGHTSPEED | Original LIGHTSPEED receiver; direct HID++ tested with G HUB closed |
| Keychron M6 | 1K Keychron Link receiver |
| Lamzu Paro | 2.4 GHz receiver and USB; on-panel disconnect and recovery checked with the receiver |
| Sony DualSense | USB and Bluetooth with extended reports; the percentage is an estimate |

**Additional profiles remain Beta.** Check the
[compatibility table](https://github.com/mor4ee/BatteryFlexBar/blob/public/docs/COMPATIBILITY.md)
for model and connection limits.

## Install and verify

Import `Battery.win32.x64.flexplugin` in FlexDesigner. Battery targets Windows
10/11 x64 and FlexDesigner Plugin API v1. The verified host baseline remains
**FlexDesigner 2.2.3**; full hardware regression on 2.2.5 Pre-release is pending.
Compare the archive hash with `SHA256SUMS.txt`:

```powershell
Get-FileHash -Algorithm SHA256 .\Battery.win32.x64.flexplugin
```
