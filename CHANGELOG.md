# Changelog

## 0.1.0-alpha.1 — Release preview

- Text-based Battery level Unit with device choice, native Foreground styling,
  tap-to-refresh, and charging/unavailable indicators.
- Verified routes for MX Master 4, G305, Keychron M6, Lamzu Paro and DualSense.
- Beta Windows Bluetooth, generic HID, additional vendor-specific profiles,
  Xbox, DualShock 4, Switch Pro and optional HeadsetControl.
- Windows x64 packaging with a clean configuration check and SHA-256 checksum.

See [compatibility](docs/COMPATIBILITY.md) for the current verification scope.
